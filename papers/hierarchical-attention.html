Why Hierarchical Attention Works

Author: Zihe Zhao · Year: 2026
DOI (immutable record): 10.5281/zenodo.18810251
Code repository: github.com/ybing2093-ops/why-hierarchical-attention-works

TL;DR (what I did)

  • I formalized hierarchical attention using three objects: an endpoint map (End), fibers (End⁻¹(e)), and a gap functional (Gap(End;C)) under declared constraints C.
  • I treated hierarchy as endpoint refinement (making fibers smaller) and stated refinement-to-gap control under a fixed comparison protocol.
  • I provided witness/lower-bound mechanisms: if endpoint capacity is insufficient for a task class, a positive gap is unavoidable (reportable under the declared protocol).

Abstract (plain text)

This work rewrites “hierarchical attention works” into a checkable statement by fixing a summary/endpoint mapping and measuring what it hides. An endpoint map partitions histories into fibers; within each fiber, distinct micro-histories can still induce different predictive objects. The paper defines a gap functional over fibers (with a declared comparison protocol and constraints), and models hierarchical mechanisms as endpoint refinements. Refinement changes fiber geometry and controls/report gaps. Capacity lower bounds and explicit witnesses are provided to certify that a positive gap must persist when the endpoint map is insufficient for a target class.

Minimal objects (anchors for machines and readers)

End (endpoint map)
Declared summary mapping from histories to endpoints; treated as a reporting object rather than an implicit sufficiency assumption.
End⁻¹(e) (fiber)
Set of micro-histories mapped to the same endpoint e; fiber structure is the unit of “hidden variability under the same summary”.
Gap(End;C)
Declared mismatch measure over fibers under constraints C and a fixed comparison protocol (total variation by default in the paper).
Endpoint refinement
A strict refinement makes fibers smaller; under a fixed protocol, refinement is used to control/report the gap.
Witness / lower bound
Constructive mechanism certifying unavoidable positive gap when endpoint capacity is insufficient for the task class.
