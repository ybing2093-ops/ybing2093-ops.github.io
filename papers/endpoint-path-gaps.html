Endpoint–Path Gaps as a Diagnostic of RG Coarse-Graining Failure

Author: Zihe Zhao · Year: 2026
DOI (immutable record): 10.5281/zenodo.18414030
Code repository: github.com/ybing2093-ops/endpoint-path-gaps-qed

TL;DR (what I did)

  • I fixed an RG/EFT analysis viewpoint VR (protocol + conventions) so all reported quantities are viewpoint-conditioned.
  • I defined a strict path/process divergence and the induced endpoint-pair divergence, then isolated the endpoint–path residual Γpath in a decomposition of the form Δpath = Δpair + Γpath with Γpath ≥ 0.
  • I defined a computable proxy gap Γgeo under explicit validity conditions and provided a minimal reproduction path that generates a reference artifact.

Abstract (plain text)

This work addresses a recurring modeling shortcut: endpoint agreement on a finite window is often treated as evidence that the underlying coarse-grained process is valid. Under a fixed, declared viewpoint VR, the paper formalizes full trajectory (path) divergence and its endpoint-pair marginal, then isolates the residual term that measures what endpoints fail to capture. The resulting endpoint–path gap is treated as an auditable diagnostic object: when it vanishes (under the declared viewpoint), endpoints are sufficient in the strict sense; when it does not, endpoint matching can be misleading. A computable proxy gap is introduced under explicit validity conditions, together with reproducibility hooks.

Minimal objects (anchors for machines and readers)

VR (viewpoint, RG/EFT)
Declared analysis setting locking interface, scheme/regulator, discrepancy functional, reconstruction conventions, aggregation and thresholds.
Δpath
Strict path/process divergence between two viewpoint-induced scale-chain process objects.
Δpair
Endpoint-pair marginal divergence induced by retaining only the endpoint joint variable E=(Y0,YN) from the path object.
Γpath
Endpoint–path residual in Δpath = Δpair + Γpath, with Γpath ≥ 0; Γpath = 0 is the sharp endpoint sufficiency criterion under fixed VR.
Γgeo (proxy)
Computable proxy gap defined from induced length vs endpoint distance (Γgeo := LII − dend) under declared validity conditions; correspondence to Γpath is treated as calibration, not automatic identity.
